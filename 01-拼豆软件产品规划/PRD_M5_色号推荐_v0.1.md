## 1. 背景与目的

### 1.1 背景
用户在 M2 照片转拼豆生成拼豆图后,会面对两个最关键的问题:
1. **用了哪些色号?** 拼豆图纸要拼出来,需要逐个核对色号
2. **色号去哪里买?** 用户不可能一个一个去淘宝搜

如果这两个问题不解决,M2 的输出对用户来说就是"看看而已",无法真正完成拼豆。

### 1.2 目的
M5 色号推荐要解决的核心问题:
1. **色号清单清晰展示**:用户一目了然需要哪些色号,各多少颗
2. **采购无缝衔接**:用户能直接拿着清单去下单(电商 V2.0),或在 APP 内看到推荐的耗材套装
3. **降低拼豆难度**:智能合并相近颜色,把"28 色作品"简化成"15 色作品"
4. **替代色推荐**:色号缺货时,推荐最接近的等价色
5. **多品牌兼容**:虽然 MVP 仅 MARD,数据结构和算法要为未来多品牌做准备

### 1.3 范围
**包含(MVP)**:
- 色号表展示(色号 + 颜色 + 颗数 + 占比 + 位置)
- 采购清单导出(图片 / Excel / PDF)
- 色号排序(按颗数 / 按色号 / 按位置)
- 耗材套装推荐(MARD 168/288/500 色套装)
- 难度调整(降低/提高色号数,重新生成)
- 历史版本对比

**不包含(MVP)**:
- 替代色推荐(V1.0,需要色板关系数据)
- 智能合并相近色(V1.0,需要后端算法升级)
- 难度评分(V2.0)
- 多品牌色板(V1.0)
- 电商导流(V2.0)

### 5.3 难度调整(L1 进阶)

#### 5.3.1 降低难度

**触发**:用户点击"降低难度"按钮

**后端处理**:
- 输入:当前拼豆图 + 色号数据 + 目标色号数(如 15)
- 算法:贪心合并 + K-means 聚类
  - 1. 计算所有色号的 RGB Lab 距离
  - 2. 用 K-means 聚类,目标 K = 15
  - 3. 把同类色号合并到聚类中心色
  - 4. 重新计算颗数
  - 5. 重新生成拼豆图
- 输出:新拼豆图 + 新色号表

**约束**:
- 色号数减少幅度:-30% / -50% / -70%(预设)
- 不允许降到 8 色以下(意义不大)

#### 5.3.2 提高精度

- 输入:当前图 + 用户指定色号数 +30
- 算法:把现有色号拆分到 K+30 个聚类中心
- 输出:新拼豆图 + 新色号表
- **MVP 暂不实现,V1.0 引入**

#### 5.3.3 难度档位

| 档位 | 色号数 | 适合 |
|------|--------|------|
| **极简** | 8-12 | 亲子、新手尝鲜 |
| **简单** | 13-20 | 新手 |
| **标准** | 21-35 | 熟手 |
| **精细** | 36-60 | 达人 |
| **极致** | 60-100 | 大神 |

用户在结果页可直接切档位重新生成。

### 7.2 数据结构

#### 7.2.1 MARD 色板基础数据(预置)

```typescript
// 服务端预置,APP 不下发
interface MardColorPalette {
  brand: "MARD";
  version: string;                  // "2026-06-01"
  colors: MardColor[];
}

interface MardColor {
  color_no: string;                 // M01
  color_name: string;
  rgb: string;                      // #RRGGBB
  lab: { L: number; a: number; b: number };  // 用于 ΔE 计算
  is_common: boolean;               // 是否常用
  category: string;                 // 类别(红/橙/黄/绿/蓝/紫/灰/黑/白/特殊)
}
```

#### 7.2.2 难度调整算法(后端)

输入:当前色号列表 (color_no, rgb, count) + 目标色号数 K
输出:新色号列表

```python
# 伪代码
def adjust_difficulty(current_colors, target_K):
    # 1. 转 Lab 空间
    colors_lab = [rgb_to_lab(c.rgb) for c in current_colors]
    weights = [c.count for c in current_colors]
    
    # 2. 加权 K-means 聚类
    from sklearn.cluster import KMeans
    kmeans = KMeans(n_clusters=target_K, weights=weights)
    labels = kmeans.fit_predict(colors_lab)
    
    # 3. 合并同类色号
    merged = []
    for k in range(target_K):
        cluster_colors = [c for i, c in enumerate(current_colors) if labels[i] == k]
        cluster_count = sum(c.count for c in cluster_colors)
        center_rgb = kmeans.cluster_centers_[k]
        # 找最接近 MARD 色板的色号作为代表
        representative = find_closest_mard_color(center_rgb)
        merged.append({
            'color_no': representative.color_no,
            'rgb': representative.rgb,
            'count': cluster_count
        })
    
    return merged
```
