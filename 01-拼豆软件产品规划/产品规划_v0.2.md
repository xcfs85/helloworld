## 1. 决策纪要(2026-06-07)

| # | 决策项 | 决议 | 影响 |
|---|--------|------|------|
| 1 | 目标用户主战场 | **C 端爱好者**(主力 22-30 岁女性) | B 端 SaaS 暂不做,资源聚焦 C 端;V3.0 再评估 |
| 2 | MVP 是否包含论坛 | **否** | MVP 周期严格控制在 2 个月,只做工具闭环 |

| 4 | 移动端技术栈 | **Flutter 跨平台** | 双端共用代码库,2 人即可覆盖;后续优化性能可混合开发 |

| 6 | 商业模式主推 | **会员制** | MVP 阶段先验证工具+会员订阅(¥18/月 起);V2.0 引入电商导流 |
| 7 | PC 端 | **不做** | 资源全部投入移动端 |

## 2. 受 v0.2 决策影响的章节(差异更新)

### 2.1 MVP 范围(更新)

**MVP(0-2 个月)包含**:
- 注册登录(M1):手机号 + 微信 + Apple ID(MVP 必选)
- 照片生成拼豆图形(M2):**仅 MARD 色板**、3 个基础尺寸(29×29 / 50×50 / 58×58)
- 色号推荐(M5):基于 MARD 色板出采购清单
- 简单作品展示:本地存储,不上传服务器
- 会员订阅:**MVP 末期(第 6-8 周)接入**,月卡 ¥18 / 季卡 ¥45 / 年卡 ¥148
- 管理后台:用户列表、生成数据看板、会员管理

**MVP 不做**:
- 论坛(整体推迟到 V1.0)
- 经典拼图模板库(M4 推迟到 V1.0)
- 拼豆材料电商(推迟到 V2.0)
- 多品牌色板(MARD 之外的全部推迟)
- 风格化(国风/像素等)功能
- PC 端

### 2.2 拼豆品牌路线图(更新)

| 版本 | 支持品牌 |
|------|----------|
| MVP | MARD |
| V1.0 | MARD + 漫漫 + 丫丫 |
| V1.5 | 引入 HAMA(高端) |
| V2.0 | 全部品牌 + 自定义色板 |

### 2.3 技术栈(锁定)

- 移动端:Flutter 3.x(双端)
- 后端 API:Go(Gin) 或 Node.js(NestJS),由团队决定
- AI 推理:Python + PyTorch,部署在**阿里云 GPU 服务器**(按量付费,选用 V100/A10 级别)
- 数据库:MySQL 8 + Redis 7
- 对象存储:阿里云 OSS
- CDN:阿里云 CDN
- 推送:极光(覆盖双端)
- 监控:Sentry + 阿里云日志服务

### 2.4 商业模式 MVP 阶段(更新)

| 项目 | 内容 |
|------|------|
| **核心变现** | 会员订阅(月卡 / 季卡 / 年卡 / 终身) |
| **会员权益** | 无限次生成、高清导出(>5000 颗)、去广告、专属客服、提前体验新功能 |
| **免费用户限制** | 每天 3 次生成、含广告、水印 |
| **单次付费** | MVP 暂不做(避免付费路径过多),V1.0 引入"大图单次 ¥3" |
| **电商** | MVP 暂不接入,V2.0 引入"色号表 → 材料包"导流 |

## 3. MVP 成功指标(更新)

| 指标 | MVP 目标(2 个月) | 验收标准 |
|------|------------------|----------|
| 注册转化率 | > 60% | 访问 → 注册 |
| 完成生成到查看色号表 | > 70% | 注册 → 看到结果 |
| 7 日留存 | > 25% | 启动后第 7 天回访 |
| 会员付费转化率 | > 3% | 注册 → 付费 |
| 日生成图纸数 | > 500 | 单日全量 |
| AI 生成 P95 延迟 | < 30s | 5000 颗以内 |
| Crash 率 | < 0.5% | 启动次数 / 崩溃次数 |
