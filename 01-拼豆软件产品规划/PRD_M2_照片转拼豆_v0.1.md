## 1. 背景与目的

### 1.1 背景
拼豆是深受年轻人和亲子家庭喜爱的手工品类,但创作门槛高——**把一张照片变成拼豆图纸需要手画几百到几千个格子、逐个确认色号**,新手往往要花几小时甚至放弃。

当前市场上的工具(拼豆图纸生成器小程序、Perler Bead Pattern 海外站)普遍存在以下问题:
- 工具零散,与社区、电商脱节
- 国产色板支持差,色号不准
- 用户完成图纸后没有后续(分享/讨论/买材料)的承接

本产品的核心价值主张:**用 AI 1 分钟把照片转拼豆图纸,让新手也能完成自己的第一个作品**。

### 1.2 目的
本 PRD 要解决的核心问题:

1. **降低创作门槛**:从"几小时画图"到"1 分钟生成"
2. **保证色号准确**:用 MARD 色板精确映射,色差 ΔE < 5
3. **跑通核心链路**:选图 → 生成 → 预览 → 色号表 → 导出 → 拼豆
4. **支撑商业模式**:为后续会员订阅、电商导流提供基础流量

### 1.3 范围
**包含**:
- 拍照/选图
- 图片编辑(裁剪、旋转、调色)
- 参数配置(总颗数、底板、难度)
- AI 生成拼豆图
- 拼豆图预览与调整
- 色号表生成与导出
- 收藏/分享

**不包含**:
- 论坛功能(V1.0 再说)
- 模板库(V1.0 再说)
- 多品牌色板(V1.0 扩展)
- 风格化(国风/油画等,V2.0 再说)
- B 端批量生成

## 2. 名词解释

| 术语 | 解释 |
|------|------|
| **拼豆** | 直径 2.6mm / 5mm 的塑料小颗粒,按图纸摆好后熨烫成型 |
| **色号** | 拼豆颜色编号,MARD 色板共 200+ 色号 |
| **底板规格** | 拼豆底板尺寸,如 29×29(配 H1 板)、50×50(配 H2 板) |
| **ΔE** | 颜色差异度量,值越小颜色越接近。ΔE < 2 肉眼难辨,< 5 可接受 |
| **MARD** | 国产拼豆品牌(本 MVP 唯一支持) |
| **同步生成** | 客户端发起请求后,服务端即时返回结果(简单图) |
| **异步生成** | 提交任务后轮询/WebSocket 推送进度(复杂图) |
| **AI 推理** | 服务端调用深度学习模型处理图像,返回拼豆数据 |
| **色板映射** | 把图像的 RGB 像素映射到最近的拼豆色号(本产品核心算法) |

### 5.4 AI 生成模块

#### 5.4.1 同步 vs 异步策略

| 条件 | 模式 | 说明 |
|------|------|------|
| 颗数 ≤ 5000 + 风格简单/写实 | 同步 | 客户端等待 30s 内返回 |
| 颗数 > 5000 或 复杂风格 | 异步 | WebSocket 推送进度,客户端可关闭页面 |

#### 5.4.2 AI 推理服务流程(后端)

```
1. 接收请求(图片 URL + 参数)
2. 图片下载 + 校验
3. AI 图像处理:
   a. 主体检测(MTCNN / MediaPipe)
   b. 智能裁剪(可选,基于人脸/显著性)
   c. 风格化处理(根据用户选的风格)
   d. 颜色量化(K-means 或中位切)
   e. 色板映射(RGB → MARD 色号,ΔE 最小)
   f. 后处理(降噪、平滑、保留细节)
4. 生成产物:
   - 拼豆图 PNG(带格线 / 不带格线)
   - 色号 JSON(色号 + 颗数 + 位置)
5. 写入 OSS + DB
6. 返回结果(同步) / 推送 WebSocket(异步)
```

#### 5.4.3 进度展示

| 阶段 | 文案 | 预计耗时占比 |
|------|------|--------------|
| 1 | 正在分析图像... | 10% |
| 2 | 正在智能裁剪... | 15% |
| 3 | 正在映射色号... | 50% |
| 4 | 正在生成图纸... | 20% |
| 5 | 即将完成... | 5% |

进度条使用真实进度(后端推送),不做假进度。

#### 5.4.4 取消与重试
- 异步任务:用户在生成页可点"取消"
- 失败自动重试 1 次,失败后提示用户"生成失败,已重试,请检查网络后重试"
- 同步任务:失败直接提示

#### 5.4.5 服务降级
- GPU 服务异常:自动降级到 CPU + 简化模型(速度慢但可用)
- 完全不可用:提示"服务维护中,请稍后重试"

#### 5.4.6 性能要求

| 指标 | 要求 |
|------|------|
| P50 延迟(同步) | < 15s |
| P95 延迟(同步) | < 30s |
| P99 延迟(同步) | < 60s |
| 异步完成时间 | < 120s |
| 队列等待时间 | < 10s |
| 并发能力(单机) | 10 路/秒 |

## 7. 数据结构与接口

### 7.1 核心实体

#### 7.1.1 Diagram(拼豆图纸)

```typescript
interface Diagram {
  id: string;                  // 唯一 ID
  user_id: string;             // 用户 ID
  name: string;                // 图纸名称
  status: 'draft' | 'generated' | 'shared';
  source_image_url: string;    // 原图 OSS 地址
  thumbnail_url: string;       // 缩略图
  preview_url: string;         // 拼豆图(带格线)
  preview_no_grid_url: string; // 拼豆图(不带格线)
  
  // 参数
  params: {
    bead_count: number;        // 总颗数
    board_size: string;        // 底板规格 29x29/50x50/58x58
    brand: string;             // 品牌 MARD
    difficulty: 'easy' | 'normal' | 'hard';
    style: 'realistic' | 'cartoon';
  };
  
  // 色号
  color_summary: {
    total_colors: number;      // 色号数
    total_beads: number;       // 总颗数
    color_list: ColorInfo[];   // 色号详情
  };
  
  // 元数据
  created_at: string;          // 创建时间
  updated_at: string;          // 更新时间
  cost_time_ms: number;        // 生成耗时
  ai_model_version: string;    // AI 模型版本
}
```

#### 7.1.2 ColorInfo(色号信息)

```typescript
interface ColorInfo {
  color_no: string;            // 色号 M01
  rgb: string;                 // RGB 值 #FF0000
  count: number;               // 颗数
  ratio: number;               // 占比 0-1
  positions: number[];         // 位置索引数组(可选,大数据量)
}
```

## 8. 异常处理与边界场景

| 场景 | 处理策略 |
|------|----------|
| **图片上传失败** | 重试 3 次,失败 Toast 提示"网络异常,请重试" |
| **图片格式不支持** | 客户端预检,Toast 提示 |
| **图片超 20MB** | 客户端预检,提示压缩 |
| **图片违规(涉政/涉黄)** | AI 审核拒绝,提示"图片不合规" |
| **图片质量太差**(全黑/全白/纯色) | 后端检测,提示"图片质量不足,建议换张" |
| **AI 推理超时**(>120s) | 自动重试 1 次,失败提示重试 |
| **AI 推理失败** | 重试 1 次,失败提示"生成失败,已自动重试,请稍后重试" |
| **生成中用户退出 APP** | 异步任务继续,结果保存云端,用户重新进入可看到 |
| **重复上传相同图片** | 哈希去重,直接返回历史结果(节省 GPU) |
| **会员过期后访问会员图纸** | 不影响查看,仅生成时受限 |
| **网络中断** | 检测后 Toast 提示,本地草稿保存 |

## 10. 风险评估

| 风险 | 等级 | 影响 | 应对 |
|------|------|------|------|
| **AI 色号映射效果差** | 🔴 高 | 用户失望,流失 | 找 5-10 名拼豆达人做种子用户,持续反馈优化;提供"反馈色号不准"入口 |
| **GPU 推理成本高** | 🟡 中 | 毛利压力 | 队列削峰 + 缓存去重 + 公有云弹性 |
| **高并发稳定性** | 🟡 中 | 服务雪崩 | 灰度发布(1% → 10% → 50% → 100%)+ 实时监控 + 自动降级 |
| **用户上传版权问题** | 🟡 中 | 法务风险 | 用户协议明确,APP 不承担版权责任;不展示用户原图,只展示拼豆图 |
| **新人不会用** | 🟢 低 | 转化率低 | 引导式 UI + 示例图 + 工具提示(Tooltip)+ 内置教程 |
| **AI 模型冷启动效果不佳** | 🟢 低 | 影响首批用户 | 用 Perler Bead Pattern 公开数据集预训练 + MARD 官方色板微调 |
| **MARD 色板更新** | 🟢 低 | 色号不准 | 后端维护色板版本,新增色号支持更新 |
