## 1. 项目概述

### 1.1 产品定位

**拼豆** 是一款面向 C 端手工爱好者的 AI 拼豆图纸生成工具，核心价值：**用 AI 1 分钟把照片转拼豆图纸，让新手也能完成自己的第一个作品**。

产品包含以下核心能力：

| 能力模块 | 说明 | 优先级 |
|----------|------|--------|
| M1 注册登录 | 多方式登录、用户体系 | P0 |
| M2 照片生成拼豆 | AI 照片转拼豆图纸 | P0 |
| M5 色号推荐 | 色号表展示、导出、采购推荐 | P0 |
| M3 论坛 | 社区分享、互动 | P1 |
| M4 经典模板 | 模板库、创作者投稿 | P1 |

### 1.2 目标用户

| 用户类型 | 特征 | 需求 |
|----------|------|------|
| **新手用户** | 22-30 岁女性，第一次接触拼豆 | 快速上手、作品分享 |
| **熟手用户** | 有拼豆经验，追求效率 | 高质量图纸、批量生成 |
| **创作者** | 拼豆博主、KOL | 社区曝光、模板变现 |

### 1.3 用户规模预测

| 阶段 | DAU | 备注 |
|------|-----|------|
| MVP 上线 | 1,000 | 种子用户 |
| V1.0 上线 | 10,000 | 社区运营 |
| V2.0 | 100,000 | 电商+模板变现 |

## 2. 功能需求

### 2.1 M1 注册登录

#### 2.1.1 登录方式

| 方式 | 优先级 | 说明 |
|------|--------|------|
| 手机号验证码 | P0 | 主力方式，11 位手机号 + 6 位验证码 |
| 微信一键登录 | P0 | 微信授权，需配置 AppID |
| Apple ID 登录 | P0 | iOS 必选，Apple 审核强制要求 |
| 游客模式 | P0 | 可体验 1 次生成，引导注册 |

#### 2.1.2 用户体系

- **Token 机制**：access_token (2h) + refresh_token (30d)
- **多设备支持**：最多 3 设备同时在线
- **账号绑定**：微信/Apple 可绑定手机号

#### 2.1.3 安全风控

- 短信防刷：60s 间隔、1 天 10 次上限
- 设备指纹：同设备 1 天最多注册 1 账号
- 图形验证码：3 次验证码错误后触发

### 2.2 M2 照片生成拼豆

#### 2.2.1 核心流程

```
选图 → 裁剪/编辑 → 参数配置 → AI 生成 → 预览/调整 → 色号表 → 导出/分享
```

#### 2.2.2 选图模块

| 功能 | 说明 |
|------|------|
| 拍照 | 调用系统相机 |
| 相册选择 | 单选，支持 JPG/PNG/WEBP/HEIC |
| 示例图 | 内置 6-8 张示例 |

**限制**：文件 ≤ 20MB，分辨率长边 ≤ 8192px

#### 2.2.3 编辑模块

| 功能 | 说明 |
|------|------|
| 裁剪 | 自由裁剪、方形裁剪、预设比例(1:1/3:4/4:3) |
| 旋转 | -180° ~ +180° |
| 翻转 | 水平翻转、垂直翻转 |
| 调色 | 亮度/对比度/饱和度各 -100 ~ +100 |

#### 2.2.4 参数配置

| 参数 | 选项 |
|------|------|
| 总颗数 | 500 / 1,000 / 2,000 / 3,000 / 5,000 / 8,000 / 10,000+ |
| 底板规格 | 29×29 / 50×50 / 58×58 |
| 难度 | 简单(8-15色) / 进阶(16-30色) / 写实(30-80色) |
| 风格 | 写实 / 卡通 |

#### 2.2.5 AI 生成

| 策略 | 条件 |
|------|------|
| 同步 | 颗数 ≤ 5,000，30s 内返回 |
| 异步 | 颗数 > 5,000，WebSocket 推送进度 |

**进度阶段**：
1. 正在分析图像 (10%)
2. 正在智能裁剪 (15%)
3. 正在映射色号 (50%)
4. 正在生成图纸 (20%)
5. 即将完成 (5%)

#### 2.2.6 预览功能

- 缩放：0.5x - 8x
- 格线开关：显示/隐藏
- 色块编号开关：显示/隐藏
- 长按查看色号详情

#### 2.2.7 历史版本

- 同一图纸最多保存 5 个版本
- 可对比选择最佳版本

### 2.3 M5 色号推荐

#### 2.3.1 色号表展示

| 字段 | 说明 |
|------|------|
| 色号 | M01、M15 等 |
| 颜色 | 颜色名称 |
| 颗数 | 该色号数量 |
| 占比 | 百分比 |
| 位置缩略图 | 标注在拼豆图中的位置 |

#### 2.3.2 排序与筛选

- 排序：按颗数(↓/↑)、按色号字母、按位置
- 筛选：全部/主色(>5%)/辅色(1-5%)/配色(<1%)

#### 2.3.3 难度调整

| 档位 | 色号数 | 适合 |
|------|--------|------|
| 极简 | 8-12 | 亲子、新手 |
| 简单 | 13-20 | 新手 |
| 标准 | 21-35 | 熟手 |
| 精细 | 36-60 | 达人 |
| 极致 | 60-100 | 大神 |

**约束**：不允许降到 8 色以下

#### 2.3.4 导出功能

| 格式 | 内容 |
|------|------|
| PNG 图片 | 拼豆图 + 色号表 |
| Excel | 色号 + 颜色 + RGB + 颗数 |
| PDF | 拼豆图 + 色号表多页 |

#### 2.3.5 耗材推荐

| 用色数 | 推荐套装 |
|--------|----------|
| ≤ 30 色 | MARD 168 色套装 (¥89) |
| 30-80 色 | MARD 288 色套装 (¥168) |
| > 80 色 | MARD 500 色套装 (¥298) |

### 2.4 M3 论坛

#### 2.4.1 帖子类型

| 类型 | 说明 | 必填字段 |
|------|------|----------|
| 作品 | 分享完成的拼豆作品 | 图片、标题 |
| 求图 | 想要某个图的图纸 | 参考图、标题、描述 |
| 教程 | 图文/视频教程 | 标题、封面、内容 |
| 讨论 | 求助/吐槽/建议 | 标题、描述 |

#### 2.4.2 帖子字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 图片/视频 | ✅(作品/教程) | 1-9张图片 或 ≤5分钟视频 |
| 标题 | ✅ | 30字以内 |
| 描述 | 教程/讨论必填 | 500字以内 |
| 话题 | ❌ | 1-3个 |
| 关联图纸 | ❌ | 可关联 M2 生成的图纸 |
| 拼豆参数 | ❌ | 板型/色号数/耗时/难度 |

#### 2.4.3 互动功能

| 功能 | 说明 |
|------|------|
| 点赞/取消 | 单击，实时显示数量 |
| 收藏 | 分类查看(作品/教程) |
| 评论 | 200字内，支持@、2级回复 |
| 分享 | 微信/朋友圈/QQ/小红书/复制链接 |

#### 2.4.4 信息流

- **关注流**：关注的人的作品，时间倒序
- **推荐流**：算法推荐(兴趣+热度+多样性)
- **话题流**：按话题聚合

#### 2.4.5 内容审核

```
发布 → AI 初审(2s) → 通过 → 发布
                ↓
            疑似违规 → 人工复审(24h) → 通过/拒绝
                ↓
            明显违规 → 直接拒绝
```

**违规处罚**：
- 第一次：警告 + 下架
- 第二次：禁言 24h
- 第三次：禁言 7 天
- 第四次：永久封禁

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 目标 |
|------|------|
| APP 启动 | < 1.5s |
