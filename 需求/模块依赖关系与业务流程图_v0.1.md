## 3. 核心业务流程

### 3.1 主业务流程（选图 → 生成 → 色号 → 导出）

```
用户
  │
  ├─→ 登录/游客 (M1)
  │        │
  │        ▼
  └─→ 选图 (M2)
          │
          ├─→ 拍照 ──→ 上传
          ├─→ 相册 ──→ 上传
          └─→ 示例图 → 上传
                    │
                    ▼
          裁剪/编辑 (M2)
          │
          ├─→ 自由裁剪 / 方形裁剪 / 预设比例
          ├─→ 旋转 / 翻转
          └─→ 亮度 / 对比度 / 饱和度
                    │
                    ▼
          参数配置 (M2)
          │
          ├─→ 总颗数: 500 / 1K / 2K / 3K / 5K / 8K / 10K+
          ├─→ 底板: 29×29 / 50×50 / 58×58
          ├─→ 难度: 简单 / 进阶 / 写实
          └─→ 风格: 写实 / 卡通
                    │
                    ▼
          AI 生成 (M2 + AI服务)
          │
          ├─→ 同步: ≤5,000颗 → 等待结果
          │
          └─→ 异步: >5,000颗 → WebSocket 进度推送
                    │  1. 分析图像 (10%)
                    │  2. 智能裁剪 (15%)
                    │  3. 映射色号 (50%)
                    │  4. 生成图纸 (20%)
                    │  5. 即将完成 (5%)
                    ▼
          预览/调整 (M2)
          │
          ├─→ 缩放 (0.5x-8x)
          ├─→ 格线开关
          ├─→ 色块编号开关
          ├─→ 长按查看色号
          ├─→ 重新生成
          └─→ 调整参数
                    │
                    ▼
          色号表 (M5)
          │
          ├─→ 查看色号统计 (总色数/总颗数)
          ├─→ 完整色号列表
          ├─→ 排序 (颗数/色号/位置)
          ├─→ 筛选 (主色/辅色/配色)
          ├─→ 点击查看位置
          ├─→ 难度调整 (极简/简单/标准/精细/极致)
          └─→ 耗材推荐 (168/288/500色套装)
                    │
                    ▼
          导出/分享
          │
          ├─→ PNG 图片
          ├─→ Excel 采购清单
          ├─→ PDF
          ├─→ 分享到微信/朋友圈/QQ/小红书
          └─→ 收藏到我的图纸库
```

### 3.2 论坛业务流程（M3）

```
用户
  │
  ├─→ 登录 (M1)
  │
  └─→ 发布帖子 (M3)
          │
          ├─→ 选择类型: 作品/求图/教程/讨论
          │
          ├─→ 填写内容
          │    ├─→ 图片/视频 (1-9张 / ≤5分钟)
          │    ├─→ 标题 (30字内)
          │    ├─→ 描述 (500字内)
          │    ├─→ 关联图纸 (可选)
          │    └─→ 话题 (1-3个)
          │
          ├─→ 预览
          │
          ├─→ 提交 → AI 审核
          │        │
          │        ├─→ 通过 → 发布成功
          │        │
          │        └─→ 疑似违规 → 人工复审 → 通过/拒绝
          │
          └─→ 保存草稿

其他用户
  │
  ├─→ 浏览信息流
  │    ├─→ 关注流
  │    ├─→ 推荐流
  │    └─→ 话题流
  │
  ├─→ 互动
  │    ├─→ 点赞/取消
  │    ├─→ 收藏
  │    ├─→ 评论/回复
  │    └─→ 分享
  │
  ├─→ 关注用户
  │
  └─→ 接收消息通知
       ├─→ 评论
       ├─→ 点赞
       ├─→ 关注
       ├─→ @我
       └─→ 系统通知
```

### 3.3 模板业务流程（M4）

```
用户
  │
  ├─→ 登录 (M1)
  │
  └─→ 模板库 (M4)
          │
          ├─→ 浏览分类
          │    ├─→ 节日 / 卡通 / 二次元 / 宠物 / 风景
          │    ├─→ 像素游戏 / 国风 / 表情包 / 文字 / 其他
          │    └─→ 运营位: Banner / 专题 / 精选
          │
          ├─→ 筛选/排序
          │    ├─→ 难度: 简单/进阶/高阶
          │    ├─→ 色号数: ≤15 / 16-30 / 31-60 / >60
          │    └─→ 排序: 热度/最新/色号数
          │
          └─→ 搜索
               ├─→ 关键词
               ├─→ 标签
               └─→ 拼音/首字母
                    │
                    ▼
          模板详情
          │
          ├─→ 大图预览 (可缩放)
          ├─→ 查看信息 (分类/难度/色号数/板型/创作者)
          ├─→ 查看色号预览 (前10个)
          ├─→ 查看同款作品
          ├─→ 收藏
          │
          └─→ 按此生成 (跳 M2)
                    │
                    ▼
          M2 创作页 (自动带入参数)
                    │
                    ▼
          后续流程同主业务流程
```

### 3.4 创作者投稿流程（M4）

```
创作者
  │
  ├─→ 登录 (M1)
  │
  └─→ 创作者中心 → 投稿
          │
          ├─→ 选择文件 (拼豆成品图 1-3张)
          │
          ├─→ 填写信息
          │    ├─→ 模板名
          │    ├─→ 分类
          │    ├─→ 标签
          │    ├─→ 拼豆参数
          │    └─→ 描述
          │

          │
          ├─→ 预览效果
          │
          └─→ 提交审核 → 等待 1-3 工作日

  │
  └─→ 审核后台
       │
       ├─→ 查看投稿
       ├─→ 审核 (版权/质量/合规/完整性)
```

## 5. 状态机

### 5.1 帖子状态机

```
[草稿] → [发布中] → [审核中] → [已发布]
                          ↓
                      [审核拒绝] → [已删除]
                          ↓
                      [已发布] → [用户删除] → [已删除]
```

### 5.2 模板状态机

```
[草稿] → [审核中] → [已发布]
                  ↓
              [审核拒绝] → [可重新编辑] → [审核中]
```

### 5.3 拼豆图纸状态机

```
[生成中] → [已生成] → [已发布] → [已删除]
               ↓
          [生成失败] → [可重试]
```

## 6. 异常流程

### 6.1 网络异常

```
用户操作
    │
    ├─→ 检测网络
    │    ├─→ 正常 → 继续执行
    │    └─→ 断开 → 提示"网络断开, 请检查后重试"
    │
    └─→ 生成中网络中断
         ├─→ 自动重试 2 次
         └─→ 失败 → 保存草稿到本地 → 提示用户
```

### 6.2 AI 生成异常

```
AI 生成任务
    │
    ├─→ 推理超时 (>120s) → 自动重试 1 次
    │
    ├─→ 推理失败 → 重试 1 次
    │
    ├─→ 服务降级 (GPU 异常)
    │    └─→ 降级到 CPU + 简化模型
    │
    └─→ 完全不可用 → 提示"服务维护中, 请稍后重试"
```
