## 1. 背景与目的

### 1.1 背景
MVP 阶段只做了工具闭环(注册→生成→色号表→导出),用户用完即走,**7 日留存目标 25%**,但工具型 APP 通常只有 15-20%。要进一步提升留存,必须做**社区**。

拼豆圈层的特点:
- 极强的 UGC 属性:用户愿意晒自己的作品
- 教程需求大:新手有强烈的"学"的需求
- 同好交流:女性/亲子/手作圈层社交属性强
- 缺乏统一平台:目前散落在小红书、抖音、B 站

### 1.2 目的
M3 论坛要解决的核心问题:
1. **承接 M2 产出**:用户生成图纸后,能直接发布到社区晒图
2. **提升留存**:通过信息流、互动、关注,把单次工具使用变成持续访问
3. **构建 UGC 飞轮**:作品 → 教程 → 互动 → 新用户 → 新作品
4. **沉淀内容资产**:作品/教程成为"模板库"前身(对接 M4)
5. **裂变拉新**:用户作品带 APP 水印分享,自然带来新用户

### 1.3 范围(V1.0)
**包含**:
- 4 种帖子类型:作品 / 求图 / 教程 / 讨论
- 帖子发布/编辑/删除
- 互动:点赞 / 评论 / 收藏 / 分享
- 关注/粉丝
- 信息流:关注 + 推荐
- 话题(轻量版 hashtag)
- 消息中心(评论/关注/点赞/系统)
- 内容审核(AI + 人工)

**不包含(V1.0)**:
- 创作者激励 / 打赏(V2.0)
- 等级体系(V1.5)
- 活动/挑战(V1.5)
- 视频教程完整编辑器(V1.5)
- 直播(V3.0)

## 2. 用户故事

**故事 1:晒作品**
> 作为拼豆玩家,我刚完成了一个作品,想分享给同好看,顺便求点赞评论。

**故事 2:求图纸**
> 作为用户,我在小红书看到一张拼豆作品很喜欢,想求原图,在 APP 内求比翻遍评论区方便。

**故事 3:看教程**
> 作为新手,我想学"如何熨烫拼豆不糊",看图文教程。

**故事 4:关注达人**
> 作为用户,发现一个高质量的拼豆博主,我想关注她,以后看她的新作品。

**故事 5:互动**
> 作为用户,看到喜欢的作品想点赞,有问题想问,想评论。

**故事 6:被提醒**
> 作为达人,有人评论了我的作品,我想收到通知,这样能及时回复。

## 4. 帖子类型详解

### 4.1 作品贴

**定义**:用户分享自己完成的拼豆作品(实物照片)

**字段**:
| 字段 | 必填 | 说明 |
|------|------|------|
| 图片(1-9 张) | ✅ | 实物照片 |
| 标题 | ✅ | 30 字以内 |
| 描述 | ❌ | 500 字以内 |
| 拼豆参数 | ❌ | 板型 / 色号数 / 耗时 / 难度 |
| 关联图纸 | ❌ | 选填,可关联 M2 生成的图纸 |
| 话题 | ❌ | 1-3 个 |
| 位置 | ❌ | 选填 |

**特殊**:
- 关联图纸后,帖子卡片显示"使用 XX 模板/AI 生成"
- 其他用户点击"求图纸"可直接跳到色号表(打通 M2/M5)

**示例卡片**:
```
┌──────────────────────────────┐
│ [头像]  小美    ·  2 小时前   │
│                              │
│ 给闺蜜的生日礼物🎁            │
│ 50×50 板 / 28 色 / 拼了 8 小时│
│                              │
│ ┌────┐┌────┐┌────┐          │
│ │ 1  ││ 2  ││ 3  │          │
│ └────┘└────┘└────┘          │
│                              │
│ #生日礼物 #闺蜜 #拼豆日常    │
│                              │
│ ♡ 1.2k  💬 89  ⭐ 234  ⤴ 分享│
└──────────────────────────────┘
```

### 4.2 求图贴

**定义**:用户想要某个图,求其他人分享或 AI 生成

**字段**:
| 字段 | 必填 | 说明 |
|------|------|------|
| 参考图 | ❌ | 1-3 张(可拍屏幕/网上截图) |
| 标题 | ✅ | "求 XX 图" |
| 描述 | ✅ | 说明图源、要求、用途 |
| 悬赏 | ❌ | 可附"完成送 M 色号"等 |

**特殊**:
- 帖子卡片显示"一键 AI 生成"按钮
- 点击后跳转 M2 创作流,自动填充参考图

### 4.3 教程贴

**定义**:图文/视频教程,教别人如何做

**字段**:
| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✅ | 简洁明了,如"新手 30 分钟做出 50×50 拼豆" |
| 封面 | ✅ | 1 张 |
| 内容 | ✅ | 富文本(图文) / 视频 |
| 难度 | ✅ | 入门 / 进阶 / 高阶 |
| 分类 | ✅ | 选豆 / 拼豆 / 熨烫 / 装裱 / 创意 |
| 关联图纸 | ❌ | 选填 |

**特殊**:
- 进入"教程专区"独立信息流
- 视频教程:V1.0 支持 5 分钟内短视频
- 教程可申请"精选教程"(运营审核)

### 4.4 讨论贴

**定义**:不针对具体作品的讨论(求助/吐槽/建议)

**字段**:
| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✅ | 提问/讨论主题 |
| 描述 | ✅ | 详细说明 |
| 关联作品 | ❌ | 选填 |

**示例**:
- "为什么我的拼豆总是歪?"
- "推荐一款性价比高的拼豆熨斗"
- "新手应该买 168 还是 288 色套装?"

## 5. 核心功能

### 5.1 帖子发布

#### 5.1.1 发布入口
- 底部 Tab 中央"+"按钮
- 作品详情页"我也想做"→ 自动跳到 M2 创作
- 求图详情页"我有这个图"→ 跳到发布

#### 5.1.2 发布流程

```
选择类型 → 编辑器(图文 / 视频) → 预览 → 发布
         ↓
      保存草稿(可稍后继续)
```

#### 5.1.3 编辑器能力

| 类型 | 能力 |
|------|------|
| **图文** | 图片(1-9 张)+ 文字(500 字)+ @用户 + #话题 |
| **视频** | 视频(≤ 5 分钟,≤ 200MB) + 封面 + 标题 + 描述 |
| **教程图文** | 富文本(图文混排,支持标题/列表/引用) |
| **教程视频** | 视频 + 章节标记(可选) |

#### 5.1.4 草稿箱
- 自动保存草稿(每 30 秒)
- 草稿保留 30 天
- "我的 - 草稿箱"查看

#### 5.1.5 关联 M2 图纸
- 作品贴发布时,可从"我的图纸库"选 1 个关联
- 关联后,帖子卡片展示"用 XX APP 生成"
- 点击图纸入口可查看完整色号表

### 5.2 互动

#### 5.2.1 点赞
- 单击点赞 / 再次点击取消
- 实时显示点赞数
- 点赞列表(谁点了赞)

#### 5.2.2 收藏
- 单击收藏 / 再次点击取消
- 收藏数显示
- "我的 - 收藏"分类查看(作品 / 教程)

#### 5.2.3 评论
- 文本评论(200 字内)
- @用户(对方收到通知)
- 回复评论(2 级回复,不再嵌套)
- 评论点赞

**评论审核**:
- AI 自动过敏感词
- 用户举报
- 频繁违规评论封禁

#### 5.2.4 分享
- 分享到微信/朋友圈/QQ/微博/小红书
- 复制链接
- 海报分享(自动生成带图海报)
- 分享追踪(短链接带用户 ID,带来源)

#### 5.2.5 浏览
- 作品/教程详情页
- 自动播放(视频)
- 上下滑动切下一个(沉浸式)

### 5.3 信息流

#### 5.3.1 关注流
- 用户关注的人的作品
- 按时间倒序
- 顶部"X 位关注的创作者有新作品"

#### 5.3.2 推荐流
- 算法推荐,基于:
  - 关注/兴趣标签
  - 互动历史(点赞/评论/收藏的帖子类型)
  - 热度(7 天内点赞数)
  - 多样性(避免信息茧房)
- 每 20 条插入 1 条"你可能认识的人"卡片

#### 5.3.3 话题流
- 按话题聚合
- 热门话题置顶
- "我在看"标签(进入话题时显示)

#### 5.3.4 算法权重(初版)

```
score = 0.3 * 关注度 + 0.3 * 互动率(点赞/评论/收藏) + 0.2 * 时新性 + 0.1 * 质量分 + 0.1 * 多样性惩罚
```

### 5.4 关注/粉丝

#### 5.4.1 关注操作
- 单击关注 / 再次点击取消
- 关注后,对方新作品进入关注流
- 互相关注 = 好友

#### 5.4.2 关注上限
- 关注别人上限:5000 人
- 被关注上限:无限
- 超过上限提示用户

#### 5.4.3 推荐关注
- "你可能认识的人"(基于共同关注/共同话题)
- 同 IP/同城市活跃用户
- 系统运营推荐(头部达人)

#### 5.4.4 黑名单
- 拉黑后:对方看不到我的内容,我看不到对方内容
- 拉黑/被拉黑双方均不通知

### 5.5 话题(轻量 hashtag)

#### 5.5.1 话题机制
- 帖子用 #xxx 标记话题
- 1-3 个/帖
- 话题广场:按热度排序
- 话题详情:该话题下所有帖子

#### 5.5.2 官方话题
- 运营可创建"官方话题"
- 头部话题有 Banner
- 例:#夏日拼豆挑战 #春节拼豆

#### 5.5.3 话题管理
- 热门话题自动发现(算法)
- 敏感话题屏蔽(AI 兜底)
- 用户举报话题

### 5.6 消息中心

#### 5.6.1 消息分类
| 类别 | 触发 | 默认 |
|------|------|------|
| **评论** | 有人评论/回复 | 开启 |
| **点赞** | 有人点赞 | 开启 |
| **关注** | 有人关注 | 开启 |
| **@我** | 有人 @我 | 开启 |
| **系统** | 官方通知 | 开启 |
| **活动** | 活动通知 | 关闭(可开) |

#### 5.6.2 消息设置
- 用户可关闭某类消息
- 关闭后不再推送通知

#### 5.6.3 未读数
- 顶部红点 + 数字
- 点击进入对应消息列表

### 5.7 内容审核

#### 5.7.1 审核流程
```
发布 → AI 初审(2s 内) → 通过 → 发布
                  ↓
              疑似违规 → 人工复审(24h 内) → 通过/拒绝
                  ↓
              明显违规 → 直接拒绝 + 提示
```

#### 5.7.2 审核维度

| 维度 | 检查项 | 处理 |
|------|--------|------|
| **政治敏感** | 涉政/涉领导人 | 拒绝 + 警告 |
| **色情低俗** | 涉黄/暴露 | 拒绝 + 警告 |
| **暴恐血腥** | 暴力/恐怖 | 拒绝 + 警告 |
| **广告营销** | 二维码/微信号/引流 | 拒绝 + 警告 |
| **版权侵权** | 未授权 IP | 警告 + 限流 |
| **垃圾内容** | 重复/无意义 | 拒绝 |
| **虚假信息** | 谣言/误导 | 限流 |

#### 5.7.3 违规处罚
- 第一次:警告 + 内容下架
- 第二次:禁言 24 小时
- 第三次:禁言 7 天
- 第四次:永久封禁

#### 5.7.4 申诉
- 任何违规处理都可申诉
- 人工 48h 内回复
- 申诉成功:撤销处罚 + 补偿

### 5.8 创作者中心(V1.5 再说,本节预留)

**V1.0 不做完整中心**,但开放基础数据:
- 作品数 / 粉丝数 / 获赞数
- 最近 7/30 天数据趋势
- 申请"创作者认证"入口

## 7. 数据结构与接口

### 7.1 核心实体

#### 7.1.1 Post(帖子)

```typescript
interface Post {
  id: string;                         // p_xxxxx
  user_id: string;                    // 作者
  type: 'work' | 'request' | 'tutorial' | 'discussion';
  title: string;
  content: string;                    // 描述/正文
  media: Media[];                     // 图片/视频
  topic_ids: string[];                // 关联话题
  
  // 拼豆相关
  bead_params?: {
    board_size: string;
    color_count: number;
    bead_count: number;
    cost_hours: number;
    difficulty: 'easy' | 'normal' | 'hard';
  };
  
  // 关联
  diagram_id?: string;                // 关联 M2 图纸
  source_post_id?: string;            // 转发来源
  
  // 互动数据(冗余,加速查询)
  like_count: number;
  comment_count: number;
  favorite_count: number;
  share_count: number;
  view_count: number;
  
  // 状态
  status: 'draft' | 'pending' | 'published' | 'rejected' | 'deleted';
  is_top: boolean;                    // 是否置顶
  is_official: boolean;               // 是否官方
  is_featured: boolean;               // 是否精选(教程)
  
  // 时间
  created_at: string;
  updated_at: string;
  published_at: string;
}
```

## 8. 异常处理

| 场景 | 处理 |
|------|------|
| **发布失败** | 保存草稿,提示重试 |
| **内容违规** | 拒绝 + 提示具体原因 |

| **加载失败** | 列表点击重试 |

| **关注自己** | 禁止 |
| **重复点赞** | 静默成功(幂等) |
| **删除自己的作品** | 弹窗二次确认 |
| **删除自己评论** | 弹窗二次确认 |
