## 1. 产品概述

### 1.1 产品愿景
打造拼豆垂直赛道的"创作 + 社区 + 工具"一体化平台,降低拼豆创作门槛,激活泛手工用户的创作欲。

### 1.2 产品形态
| 端 | 形态 | 主要场景 |
|----|------|----------|
| **移动端 APP** | iOS + Android 原生(或 Flutter 跨平台) | 用户主战场:拍照、生成、浏览作品、发帖 |
| **管理后台** | Web(PC 端) | 内容审核、用户管理、模板管理、数据看板、AI 模型配置 |
| **AI 推理服务**(配套) | 云端微服务 | 图像处理、色号映射、推荐算法 |

### 1.3 核心价值主张
- **对用户**:1 分钟把照片转拼豆图纸,免去手画格子的痛苦,新手也能上手
- **对社区**:有作品展示、有教程可学、有同好可交流
- **对平台**:高频工具 + 社区粘性 + 电商/会员变现

## 2. 目标用户画像

### 2.1 核心用户:C 端拼豆爱好者(主力)

| 维度 | 描述 |
|------|------|
| **年龄** | 18-35 岁(主力 22-30) |
| **性别** | 女性占比 70%+ |
| **城市** | 二线及以上,集中在学生 / 白领 / 宝妈 |
| **收入** | 中等,客单价敏感度中等 |
| **使用场景** | 周末/晚上空闲、孩子礼物、解压、向朋友炫耀 |
| **核心痛点** | ① 画图纸耗时 ② 找色号麻烦 ③ 没有同好交流 ④ 作品难以展示 |
| **触媒渠道** | 小红书、抖音、B 站、淘宝 |

### 2.2 次要用户

- **B 端学校/培训机构**:采购 SaaS 用于美术课、手工课(待 V2.0 探索)
- **拼豆博主/达人**:对工具和曝光有强需求,可作为种子用户
- **亲子家庭**:父母带 6-12 岁孩子一起玩,亲子场景

### 2.3 用户旅程概览

```
注册 → 看到作品(被吸引) → 拍照/选模板 → 生成图纸 → 看色号表 → 拼豆 → 拍照上传分享 → 关注达人 → 持续创作
                                                                                          ↓
                                                                                  (变现)买拼豆材料/开会员
```

## 3. 商业模式

**混合模式:基础免费 + 增值服务 + 电商导流**(不依赖单一变现,提升 LTV)

| 模式 | 具体形态 | 优先级 |
|------|----------|--------|
| **免费 + 增值** | 注册即用基础功能,VIP 解锁无限生成、高清导出、去广告、专属模板 | P0(主变现) |
| **单次付费** | 单张高分辨率大图(>200×200 颗)按次收费(¥1-3/次) | P0 |
| **电商导流** | 接入拼豆材料/工具店铺(自营 or CPS 分佣) | P1(毛利高) |
| **广告** | 信息流广告(社区列表) | P2(谨慎,影响体验) |
| **B 端 SaaS** | 培训机构批量账号 + 教学模板 | P3(战略储备) |

**VIP 定价建议(待市场验证)**:
- 月卡:¥18 / 30 天
- 季卡:¥45(7.5 折)
- 年卡:¥148(约 6.8 折)
- 终身卡:¥298(限时)

## 4. 核心功能详解(对应 5 大需求)

### 4.1 模块总览

| 编号 | 模块 | 优先级 | 复杂度 | 备注 |
|------|------|--------|--------|------|
| M1 | 注册登录 | P0 | 低 | 必经路径 |
| M2 | 照片生成拼豆图形 | **P0(核心)** | **高** | 产品灵魂,AI 能力 |
| M3 | 论坛功能 | P1 | 中 | 社区是留存和裂变的关键 |
| M4 | 经典拼图模板 | P1 | 低 | 拉新+降低门槛 |
| M5 | 色号推荐 | **P0(核心)** | **中** | 配合 M2,影响最终成品 |

### 4.2 M1 注册登录

**目标**:30 秒内完成,降低流失。

**功能要点**:
- 手机号 + 验证码(国内主力)
- 微信一键登录(iOS/Android 通用)
- Apple ID(iOS 必备,审核要求)
- 第三方账号绑定(已登录后绑定手机号,提升留存)
- 游客模式:可不登录生成 1-2 次,引导注册

**非功能需求**:
- 隐私协议、用户协议
- 实名认证(预留,用于后续合规)

### 4.3 M2 照片生成拼豆图形 ⭐核心

**用户故事**:
> 作为一名拼豆新手,我想把刚拍的照片变成拼豆图纸,这样我就能照着拼出自己的作品。

**核心流程**:
```
选图(拍照/相册) → 裁剪/调整 → 选择拼豆尺寸(总颗数) → 选择底板规格(29×29 / 50×50 / 73×73...)
   ↓
点击"生成"(后端 AI 推理,10-30s) → 预览拼豆图 → 调整 → 导出(色号表/示意图/可购买清单)
```

**关键参数**(用户可调):
- **拼豆总数**:500 / 1000 / 2000 / 5000 / 10000+
- **底板规格**:29×29 / 50×50 / 58×58 / 73×73(对应不同拼豆品牌)
- **难度**:简单(色块少)/ 进阶(细节多)/ 写实(高保真)
- **色号品牌**:MARD(马甸)/ 漫漫 / 丫丫 / HAMA(进口)
- **风格**:卡通 / 写实 / 像素风 / 黑白线稿

**AI 处理链路(后端)**:
1. **预处理**:人脸检测、主体分割、智能裁剪
2. **风格化**:根据用户选的"难度/风格"做后处理
3. **色板映射**:核心算法——把 RGB 像素映射到最近色号
4. **后处理**:降噪、平滑、保留关键特征
5. **生成输出**:图纸(带格线)+ 色号统计表(色号+数量+位置)

**验收标准**:
- 5000 颗以内的图,生成时间 < 30s
- 色号映射误差 ΔE < 5(肉眼难辨)
- 关键特征(人脸/标志)还原度 > 80%(用户调研)
- 支持主流 4 大拼豆品牌的色板

### 4.4 M3 论坛功能

**子功能**:
- **发布作品**:图片 + 标题 + 描述 + 拼豆参数(板型/色号数/耗时)
- **求图纸**:用户求特定图,其他用户上传/AI 生成
- **教程**:图文 / 视频教程(可投稿)
- **话题/挑战**:官方发起"# 夏日拼豆挑战"等
- **点赞、评论、收藏、关注**
- **消息中心**:评论、关注、点赞、系统通知

**信息流策略**:
- 关注流 + 推荐流(基于兴趣标签)
- 推荐权重:完成度高的作品 > 新发布 > 互动率高

**审核机制(后台)**:
- AI 初审(图文违规、涉政涉黄)+ 人工抽审
- 用户举报通道

### 4.5 M4 经典拼图模板

**模板分类**:
- 卡通角色(动漫 IP/经典卡通——需注意版权)
- 节日主题(圣诞、新年、春节)
- 宠物(猫/狗/仓鼠)
- 风景(山、海、樱花)
- 国风/二次元
- 像素游戏角色(吃豆人、马里奥——部分需授权)

**来源**:
- 官方设计(自营)
- 达人投稿(给稿费/分润)
- 用户共创(UGC 激励)

**功能**:
- 按分类/热度/最新浏览
- 一键"按此生成"(AI 重新映射到不同尺寸)
- 收藏 → 进入"我的模板库"

### 4.6 M5 色号推荐 ⭐核心(与 M2 紧密配合)

**两层逻辑**:

**L1 拼豆生成时**(生成过程中自动产出):
- 当前图纸用到了哪些色号
- 每个色号分别多少颗
- 总颗数、估算耗材包数

**L2 主动推荐**(独立功能):
- 用户选"图纸 + 拼豆品牌"→ 推荐匹配度最高的色号
- 支持"等价色号":如果某个色号缺货,推荐最接近的替代
- 显示每个色号的库存状态(可对接电商,引导购买)
- 支持导出**采购清单**(Excel/图片),方便用户一次性买齐

**L3 进阶(预留)**:
- 智能合并:把相近色号合并,降低颜色数(降低难度)
- 难度评估:当前图纸对新手友好度(0-10 分)

### 5.2 MVP(0-2 个月)— 验证核心价值

**目标**:验证"照片→拼豆图纸"这个核心链路用户买不买单。

**包含功能**:
- 注册登录(M1 简化版)

**不做**:
- 论坛发帖
- 模板库浏览
- 支付/会员
- 复杂运营工具

**关键指标**:
- 完成生成到查看色号表的转化率 > 60%
- 7 日留存 > 20%
- 单用户平均生成次数 > 3

### 5.4 V2.0(4-8 个月)— 商业化 + 社区

- 拼豆达人 / 等级体系
- 跨平台分享优化(微信/抖音/小红书)

**关键指标**:
- 月 GMV > 50 万

- 30 日留存 > 25%

### 5.5 V3.0(8-12 个月)— 规模化

### 6.2 关键技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| **移动端** | Flutter 跨平台 | 节省人力,2 人即可覆盖双端 |
| **后端** | Go / Node.js / Python(看团队) | AI 部分建议 Python(算法生态好) |
| **数据库** | MySQL + Redis | 主流稳定,社区方案成熟 |
| **AI 推理** | PyTorch + GPU 云服务 | 图像处理主流 |
| **对象存储** | 阿里云 OSS / AWS S3 | 图片、视频、模型文件 |
| **CDN** | 阿里云 / 腾讯云 CDN | 静态资源加速 |
| **推送** | 极光 / 个推 | 双端覆盖 |
| **监控** | Sentry + 自建日志 | 性能 + 异常监控 |

### 6.3 AI 推理服务设计要点

- **同步 vs 异步**:
  - 简单图(≤3000 颗):同步返回,>30s 必须异步
  - 复杂图:异步,客户端轮询/WebSocket 推送进度
- **队列削峰**:高并发时排队,避免 GPU 资源打爆
- **结果缓存**:相同输入哈希缓存,减少重复计算
- **降级策略**:模型服务异常时,降级到简化版算法

### 6.4 管理后台核心模块

| 模块 | 功能 |
|------|------|
| **用户管理** | 用户列表、封禁/解封、用户画像 |
| **内容审核** | 帖子/评论审核队列、AI+人工协同 |
| **模板管理** | 模板上架/下架、分类管理、达人投稿审核 |
| **数据看板** | DAU/MAU/留存/付费/生成量 |
| **AI 模型配置** | 色板版本管理、模型 A/B 测试 |
| **运营工具** | Banner 配置、Push 推送、优惠券发放 |

## 8. 风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| **AI 色号映射效果差** | 高 | 早期用众包(达人反馈)持续优化;提供人工微调工具 |
| **版权问题**(用户上传照片/动漫 IP) | 高 | 用户协议明确免责;论坛侵权投诉通道;避免官方使用未授权 IP |
| **拼豆品牌色板不统一** | 中 | 主流品牌全覆盖;用户可手动切换色板版本 |
| **生成速度慢影响体验** | 中 | GPU 弹性扩容;简化版模型兜底;异步生成 |
| **社区氛围恶化** | 中 | 早期种子用户筛选;社区规范;敏感词过滤;举报机制 |
| **变现路径长** | 中 | 早期通过"色号表 → 拼豆材料"电商导流验证变现意愿 |
| **跨平台开发质量** | 低 | Flutter 主流稳定;关键路径(生成)双端自测覆盖 |
| **竞品快速跟进** | 低 | 拼豆赛道相对小众;社区壁垒一旦建立难复制 |

## 9. 关键决策点(需用户/团队确认)

> 以下是文档中的关键假设,**确认后再进入 PRD 撰写阶段**会更精准。

1. **目标用户主战场**:
   - (A) C 端爱好者(推荐,假设 22-30 岁女性为主)
   - (B) 亲子家庭
   - (C) B 端学校机构(MVP 不做,V3 探索)

2. **MVP 是否包含论坛**:
   - (A) 不包含(MVP 只做工具,2 个月可上线,推荐)
   - (B) 包含基础发帖(MVP 周期延至 3 个月)

3. **拼豆品牌主推哪个**:
   - (A) MARD(国产高性价比,色号全,推荐)
   - (B) HAMA(进口高端,色号少)
   - (C) 全部支持(开发成本+30%)

4. **移动端技术栈**:
   - (A) Flutter 跨平台(2 人覆盖双端,推荐)
   - (B) 原生 iOS Swift + Android Kotlin(体验好,人力×2)

5. **AI 推理部署**:
   - (A) 自建 GPU 服务(成本高,数据安全)
   - (B) 公有云 API(推荐,MVP 阶段灵活)
