## 1. 背景与目的

### 1.1 背景
MVP 阶段用户必须上传照片才能生成拼豆图,这一步骤对新用户是巨大门槛:
- 没照片 / 不会拍照 / 照片质量差
- 想做一个通用图案(圣诞树、卡通角色)但找不到参考
- 怕隐私(不想上传自己的照片)

**经典拼图模板** = 现成的拼豆图,用户选个喜欢的直接生成。零门槛,新手友好,且自带传播属性(用户用模板做出来,自然带 APP 分享)。

更重要的是,**模板是连接 M3 论坛的桥梁**——论坛中优质 UGC 作品(用户授权后)可成为模板,实现社区→资产→工具的飞轮。

### 1.2 目的
M4 经典模板要解决的核心问题:
1. **降低创作门槛**:用户不需要照片,直接选模板生成
2. **冷启动内容供给**:50-200 个官方模板,用户首次进入有内容可用
3. **UGC 资产化**:论坛优质作品可沉淀为模板(创作者激励)
4. **提升生成频次**:模板不耗用户自己素材,使用频率更高
5. **节日的爆发力**:节日模板可拉动短期 DAU 暴涨(春节、圣诞、七夕等)

### 1.3 范围(V1.0)
**包含**:
- 模板分类、浏览、搜索
- 模板详情(预览图、色号数、难度、相关参数)
- 一键"按此生成"(跳 M2 流程,自动套用模板参数)
- 收藏模板
- 模板来源:官方自营 + 达人投稿
- 创作者投稿流程 + 审核
- 运营位:首页 Banner、专题、节日活动

**不包含(V1.0)**:
- UGC 模板自动从论坛同步(需论坛运营 1 个月后再开, V1.5 考虑)
- 模板分润/激励(V2.0)
- 模板购买/付费(V2.0 考虑,部分精品模板)
- 用户自制模板(V2.0,DIY 模板编辑器)

## 4. 整体架构

### 4.1 信息架构

```
[首页 - 推荐位]
   ├── Banner(运营活动位)
   ├── 节日专题(春节/圣诞/七夕)
   ├── 本周热门
   └── 编辑精选

[模板库(发现页 Tab 2)]
   ├── 分类 Tab(节日/卡通/...)
   ├── 筛选(难度/色号数/板型)
   ├── 排序(热度/最新/色号数)
   └── 搜索

[模板详情页]
   ├── 大图预览
   ├── 信息(分类/难度/色号数/板型/创作者)
   ├── 关联作品(其他用户做出来的)
   ├── 色号预览
   ├── "按此生成"按钮(主)
   ├── 收藏/分享
   └── 评论区(同款作品)

[我的 - 收藏]
   └── 收藏的模板

[创作者中心 - 投稿]
   └── 投稿流程(详见 5.6)
```

### 4.2 数据流转

```
[创作者投稿] → 审核 → 官方模板库
                            ↓
[用户浏览模板] → 选模板 → 按此生成(跳 M2) → 生成结果
                            ↓
[用户结果发布] → 论坛(M3)
                            ↓
[其他用户] → 求同款 → 回到模板详情
```

这就是"M2 工具 + M3 社区 + M4 模板"的飞轮。

### 5.3 按此生成(打通 M2)

#### 5.3.1 流程

```
[模板详情] → 点击"按此生成"
   ↓
[M2 创作页] 自动带入:
   - 模板图片作为参考图
   - 板型(50×50)
   - 总颗数(5000)
   - 风格(写实/卡通)
   - 难度(简单/进阶/写实)
   ↓
[用户可调整参数] → 提交生成
   ↓
[M2 AI 推理] → 出图
```

#### 5.3.2 模板参数锁定
- 模板有默认板型/色号数,用户可改
- 改后按新参数重新生成(可得到不同效果)

### 5.6 创作者投稿

#### 5.6.1 投稿流程

```
[创作者中心] → [我要投稿]
   ↓
[选择文件] 从本地图库选拼豆图(可 1-3 张,展示成品效果)
   ↓
[填写信息]
   - 模板名
   - 一级分类
   - 标签(主题/对象/难度/色号数/场景)
   - 拼豆参数(板型/色号数/总颗数/耗时)
   - 描述(设计理念/技巧/故事)
   ↓
[上传拼豆图(系统识别)]
   - 用户上传图纸(PNG/PDF)
   - 系统识别色号、颗数
   - 用户确认
   ↓
[预览效果] 系统自动生成模板卡片的预览
   ↓
[提交审核] → 等待 1-3 个工作日
   ↓
[审核结果]
   ├── 通过 → 模板上架,创作者收到通知 + 积分
   └── 拒绝 → 通知 + 拒绝原因,创作者可修改重提
```

#### 5.6.2 创作者资格
- V1.0:仅邀请制,运营主动招 KOC
- V1.5:开放申请,需通过"创作者认证"
- V2.0:全开放,加积分门槛

#### 5.6.3 审核维度

| 维度 | 检查项 |
|------|--------|
| **版权** | 原创/已授权/无侵权 |
| **质量** | 拼豆图清晰、色号识别准确 |
| **合规** | 无违规内容 |
| **完整性** | 信息齐全(参数/标签/描述) |
| **难度匹配** | 标注的难度与实际色号数一致 |

#### 5.6.4 创作者激励(V2.0 再说,V1.0 仅展示感谢)
- V1.0:创作者主页显示"已投稿 X 个模板",无金钱激励
- V2.0:模板被使用 N 次 → 1 元激励(暂定)
- V2.0:创作者等级 + 流量扶持

## 7. 数据结构与接口

### 7.1 核心实体

#### 7.1.1 Template(模板)

```typescript
interface Template {
  id: string;                         // t_xxxxx
  name: string;                       // 圣诞老人
  description?: string;               // 设计说明
  category: TemplateCategory;         // 分类
  tags: string[];                     // 标签
  cover_url: string;                  // 封面图
  preview_urls: string[];             // 预览图(1-3 张)
  source_diagram_id?: string;         // 关联 M2 图纸(可选)
  
  // 拼豆参数
  bead_params: {
    board_size: string;               // 50x50
    color_count: number;              // 28
    bead_count: number;               // 5000
    difficulty: 'easy' | 'normal' | 'hard';
    estimated_hours: number;          // 8-10
    style: 'realistic' | 'cartoon';
  };
  
  // 色号(冗余存储,加速列表展示)
  color_summary: {
    total_colors: number;
    total_beads: number;
    main_colors: ColorPreview[];      // 前 10 个色号
  };
  
  // 来源
  source_type: 'official' | 'creator';
  creator_id?: string;                // 投稿创作者
  creator_name?: string;              // 创作者展示名
  creator_avatar?: string;
  
  // 互动数据
  view_count: number;
  like_count: number;
  favorite_count: number;
  use_count: number;                  // 被"按此生成"次数
  
  // 状态
  status: 'draft' | 'pending' | 'approved' | 'rejected' | 'offline';
  is_featured: boolean;               // 是否精选
  is_official: boolean;               // 是否官方
  
  // 时间
  created_at: string;
  updated_at: string;
  published_at: string;
}

type TemplateCategory = 
  | 'festival'    // 节日
  | 'cartoon'     // 卡通
  | 'anime'       // 二次元
  | 'pet'         // 宠物
  | 'scenery'     // 风景
  | 'pixel_game'  // 像素游戏
  | 'chinese'     // 国风
  | 'emoji'       // 表情包
  | 'text'        // 文字
  | 'other';      // 其他
```

## 8. 异常处理

| 场景 | 处理 |
|------|------|
| **列表加载失败** | 点击重试 + 展示骨架屏 |
| **详情加载失败** | Toast"加载失败" + 返回 |
| **收藏失败** | Toast"操作失败,请重试" |
| **搜索无结果** | 显示"暂无结果" + 推荐热门 |
| **投稿失败** | 保存草稿,Toast 提示 |
| **投稿被拒** | 通知 + 拒绝原因 + 重新编辑入口 |
| **模板已下架** | 详情页提示"该模板已下架" + 推荐相似 |
| **网络异常** | Toast 提示 |

## 10. 风险评估
